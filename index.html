ScolarRecord

Sistema de registro escolar por consola desarrollado en C++23. Valida, captura y almacena datos de alumnos con generación automática de IDs únicos y una interfaz visual con arte ASCII.

README.md — descripción

Proyecto

ScolarRecord es una aplicación de terminal que simula el registro de alumnos de una institución educativa. Cada alumno requiere nombre completo, fecha y lugar de nacimiento, sexo, grado, grupo y promedio final.

El sistema valida cada campo de forma independiente en múltiples capas, mostrando el contexto de datos ya ingresados solo cuando ocurre un error. Al finalizar, genera automáticamente un ID único de 8 dígitos por alumno.

🔒

Validación Robusta

Verificación en múltiples capas por campo, con manejo de excepciones.

🆔

IDs Únicos

Generación aleatoria con std::random_device garantizando unicidad.

🖥️

Arte ASCII

Banners y menús visuales construidos completamente en consola.

🌐

Multiplataforma

Compatible con Windows, Linux y macOS via compilación condicional.

register.cpp — flujo de captura

Flujo del Programa

Cada campo se captura en su propio bucle de validación. Si hay error, se muestra el contexto de los datos ya ingresados. Si la construcción del struct falla, se reinician todos sus campos.

1 Ingresa cantidad de alumnos
↓
2 Nombre → Apellido Paterno → Apellido Materno
↓
3 Día → Mes → Año de Nacimiento
↓
4 Ciudad → Estado → País
↓
5 Sexo → Grado → Grupo → Promedio
↓
6 Generación automática de ID
↓
7 Pantalla de confirmación → Guardar
validators.cpp — reglas de validación

Validaciones

CampoRegla
Nombre / ApellidosSolo letras y espacios, no vacío
DíaSolo dígitos, máx 2 chars, rango 1–31
MesSolo dígitos, máx 2 chars, rango 1–12
AñoSolo dígitos, máx 4 chars, desde 1930
Fecha completaValidada con std::chrono, no puede ser futura
Ciudad / Estado / PaísSolo letras y espacios, no vacío
SexoUn carácter: M o F
GradoEntero entre 1 y 8
GrupoUna sola letra A–Z
PromedioDecimal entre 0.0 y 10.0

⚠ PROYECTO INCOMPLETO Y ABANDONADO

Este proyecto fue desarrollado como ejercicio de aprendizaje. Durante el desarrollo se adquirió conocimiento sobre bases de datos relacionales, lo que hace que almacenar registros en memoria a través de una interfaz de consola sea poco práctico para un sistema real. Una solución con SQL o SQLite resolvería de forma más adecuada los problemas de persistencia, búsqueda y escalabilidad que este proyecto intentaba abordar manualmente.

El código queda disponible como referencia de aprendizaje en C++23.
